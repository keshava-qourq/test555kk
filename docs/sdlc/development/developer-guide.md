TEST555 ("Chatbot") is a two-application repository generated by the Quorq AI SDLC platform: a React 19 + Vite single-page frontend containing the approved, reviewed screens (currently rendering seeded sample data, not live API calls), and a FastAPI backend scaffold that has no approved architecture yet beyond a health check endpoint and the plumbing (SQLAlchemy models, Pydantic schemas, routers package) to add real endpoints. <!-- sdlc:auto:start setup -->
1. Clone the repository
2. cd frontend && npm install
3. cd backend && pip install -r requirements.txt
4. (optional) copy .env.example to .env and set DATABASE_URL / ALLOWED_ORIGINS / VITE_API_BASE_URL as needed
5. (optional) docker-compose up -d to start Postgres and Redis if targeting the approved architecture instead of local SQLite

<!-- sdlc:auto:start conventions -->
- Backend: one router per architecture component that owns endpoints; every generated route is a stub returning a typed StubResponse until implemented
- Backend: Base (SQLAlchemy declarative base) in database.py, all models imported in main.py before Base.metadata.create_all so tables register
- Backend: request-scoped DB session via the get_db dependency, one session per request
- Backend: DATABASE_URL env var selects the database (SQLite default); ALLOWED_ORIGINS env var (comma-separated) configures CORS instead of hardcoding origins
- Frontend: path alias @/* maps to src/ (configured in tsconfig.json and vite.config.ts)
- Frontend: API base URL and shared secret come from VITE_API_BASE_URL / VITE_API_SECRET_KEY env vars; apiFetch in src/lib/api.ts centralizes authenticated fetch calls, preferring a session token (localStorage) over the shared secret
- Frontend: component/unit tests live beside the components they cover and are matched by src/**/*.{test,spec}.{ts,tsx}; Playwright e2e specs live in e2e/ and match *.spec.ts
<!-- sdlc:auto:end conventions -->

<!-- sdlc:auto:start troubleshooting -->
| Problem | Solution |
|---|---|
| Frontend calls to the backend fail with a CORS error in the browser | Set ALLOWED_ORIGINS on the backend to include the frontend's origin (defaults to the Vite dev server origins http://localhost:5173 and http://127.0.0.1:5173) |
| `npm run build` succeeds but the app fails type checking later | Run `npm run typecheck` (tsc --noEmit) separately, since build does not typecheck |
| Playwright e2e tests fail to start | Run `npm run test:e2e:install` first to fetch the Chromium browser; ensure backend deps are installed in backend/.venv since the e2e webServer runs `.venv/bin/python -m uvicorn ...` |
| Backend has no persistent/shared database between runs | Set DATABASE_URL to point at the Postgres instance started via `docker-compose up -d` instead of relying on the default SQLite file (./app.db) |
| `pytest` run from backend/ can't import app | Ensure pytest.ini's pythonpath=. is honored by running pytest from the backend/ directory |
